Gamma is an application for drawing Minkowski spacetime diagrams.

Note: This file is generated by Maven. Do not edit manually.

* INSTALLERS ARE AVAILABLE FOR WINDOW, MACOS, AND DEBIAN-BASED LINUX DISTRIBUTIONS
* THERE IS ALSO A UNIVERSAL ZIP FILE

For installation instructions, go to https://github.com/freixas/gamma

Known Problems:

  * Touch gestures for zoom/pan don't work well. Use Ctrl+0 to restore the
    original display. On my HP table, a two-finger zoom worked fine on the
    mouse pad.

  * When using Snap versions of browsers on Linux, the help files may not
    appear. One solution is to set your default browser to a non-Snap version.
    An alternative is to view the documentation directly in /opt/gamma/help.
