Status Line

The status line is located at the bottom of the window.

Coordinate Area

The coordinate area is located on the left side of the status line and displays the rest frame coordinates of the current cursor position.

Animation Area

The animation area consists of a frames-per-second (FPS) display, a speed selector, and animation buttons that control the animation.

FPS Display

When an animation is running, this displays the measured FPS rate. An animation with speed 1 should display at 30 FPS. Whether this speed is obtained may depend on the system and the complexity of the script.

Speed Selector

The speed selector allows you to select on of several fixed speeds: 0.1X, 0.25X, 0.5X, 1X, 2X, 4X, and 10X. When the animation is running, you can also increment and decrement the animation speed using the up and down arrows on the keyboard.

Animation Buttons

The animation buttons are located on the right side of the status line and are active when the current script is animated. In the following descriptions, the term "frame" refers to a frame in an animation rather than an inertial frame.

Go to the first frame in the animation.

Go to the previous frame in the animation.

You can use this button to pause or resume the animation (the icon shown is for the mode you will enter, not the mode currently enabled).

Go to the next frame in the animation.

Go to the last frame in the animation.
